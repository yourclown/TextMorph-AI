# AI Text Transformer (React + Node.js)

An AI-powered app to transform your text based on genre, with user authentication, credits, and payments.

## 🔧 Tech Stack
- Frontend: React
- Backend: Node.js + Express
- DB: MongoDB
- Auth: JWT
- Deployment: Vercel + Render

## 💻 Running Locally
```bash
cd server
npm install
npm run dev

cd ../client
npm install
npm start
